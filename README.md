# Enhancing Urban Living Through AI-Driven Context-Aware Recommendation Systems

## Overview

This project is an AI-driven smart city recommendation system designed to help users discover essential nearby services based on their real-time location and contextual needs.

The system provides intelligent recommendations for services such as hospitals, restaurants, pharmacies, ATMs, and other urban facilities by combining location awareness, distance-based filtering, and contextual relevance.

The goal is to improve urban living by helping users make faster and smarter decisions in real-time.

---

## Features

* Real-time location-based service recommendations
* Context-aware intelligent filtering
* Distance-based ranking for nearby services
* Interactive map visualization
* Responsive frontend for better user experience
* Fast backend API for recommendation processing

## Project Architecture

1. User shares location or current coordinates
2. Frontend sends request to backend API
3. Backend processes location data
4. Recommendation engine ranks nearby services
5. Results are displayed on interactive map

## Installation

### Clone Repository

```bash
git clone https://github.com/Arunkumar6256/Enhancing-Urban-Living-Through-AI-Driven-Context-Aware-Recommendation-Systems.git
```

### Navigate to Project Directory

```bash
cd Enhancing-Urban-Living-Through-AI-Driven-Context-Aware-Recommendation-Systems
```

### Backend Setup

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend Setup

```bash
npm install
npm start
```
